# Brugty font

Lege hier die Schriftdatei(en) für "Brugty" ab, dann greift automatisch das
`@font-face` in `static/css/style.css`:

- `Brugty.woff2` (bevorzugt)
- `Brugty.woff`
- `Brugty.ttf`

Bis die Datei vorhanden ist, fällt die Seite auf eine ähnliche
Fallback-Schrift zurück (`Baloo 2` / `Comic Sans MS` / cursive).
