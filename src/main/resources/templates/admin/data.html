Achtung: Ein Import ersetzt alle aktuellen Daten und Bilder unwiderruflich durch den Inhalt der ausgewählten Datei - das kann nicht rückgängig gemacht werden. Erstelle im Zweifel vorher selbst einen Export als Sicherung. Falls der Import an der Dateigröße scheitert, APP_MAX_UPLOAD_SIZE/APP_MAX_UPLOAD_REQUEST_SIZE in der .env erhöhen.
